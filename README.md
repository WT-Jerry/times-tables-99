# 趣味九九乘法表

給小學二年級練習九九乘法的手機網頁遊戲。

## 開啟

手機瀏覽器：

https://wt-jerry.github.io/times-tables-99/

## 這一版有什麼

- 森林卡通主畫面（齒輪、父母須知、大顆「玩」）
- 可愛狗狗角色
- 設定：音效開關、小朋友稱呼（只存在這台裝置）
- 關卡選擇：點 1～9，一次只能選一顆；選好後按「開始挑戰」
- 關卡頁目前先確認有進到對的號碼，題目下一回合再接

## 檔案

- `index.html` 主畫面
- `select.html` 關卡選擇
- `play.html` 關卡頁
- `styles.css` / `game.css` / `tokens.css` / `app.js` / `select.js`
- `assets/` 背景、角色與選關底圖
